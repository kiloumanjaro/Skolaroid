# Book Cover Spring Prompt

This prompt assumes the stylized open book or journal is already built, and the two inner page edges already have their own spring styling. The only missing piece is the spring implementation on the book cover that visually connects both page springs across the center seam.

## Prompt

```text
The stylized open book / journal is already created, and both pages already have spring styling on their inner edges. Do not redesign the book, pages, or layout. Only implement the missing spring styling on the book cover so it visually connects the existing page springs across the center seam.

What to add:
- Add exactly three small horizontal spring connector lines on the book cover at the center seam.
- These three connector lines must belong to the cover layer, not the page layers.
- Space them vertically so they align precisely with the existing spring pieces already attached to the left and right pages.
- Their job is to bridge the gap between the page springs so the viewer perceives one continuous spiral / notebook binding running across the entire component.

Visual behavior:
- The three lines should feel structural, not decorative.
- They should look like the center link of the spring system, completing the illusion that the spring sits on top of the whole book.
- Keep the shapes rounded and minimal so they blend naturally with the existing page spring styling.
- The alignment is critical: each cover connector should line up cleanly with the spring elements already present on both pages.

Color rules:
- The book cover must use only one single solid color.
- Do not introduce gradients, secondary cover tones, highlights, or accent colors on the cover.
- The only other color allowed besides the single book cover color is `#b0b0b0`.
- Use `#b0b0b0` only for the spring / binding pieces, including the three connector lines on the cover.
- Do not use any other spring color.

Important constraint:
- Since the page springs already exist, only add the cover-based center connector spring pieces needed to unify them.
- The final result should make the binding appear continuous, even though it is constructed from page-edge spring parts plus three cover-mounted connector lines.
```
